## featured projects

**[AI Search Engine](https://github.com/barissurkit/ai-search-engine)**: a research workspace that combines live web search, selected-document retrieval, and hybrid RAG. Every answer streams over SSE and keeps its sources inspectable. Built with React, FastAPI, Qdrant, and Ollama.

**[DevLens](https://github.com/barissurkit/DevLens)**: analyzes public GitHub portfolios with deterministic repository scoring, then optionally adds an AI interpretation on top. Built with Next.js, FastAPI, and PostgreSQL.
