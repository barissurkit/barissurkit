## Kullanım

Bu repository'nin adı GitHub kullanıcı adımla aynı olduğu ve herkese açık olduğu için `README.md` içeriği otomatik olarak <https://github.com/barissurkit> profil sayfasında gösterilir. Yerelde bir değişikliği doğrulamak için testleri çalıştırın:

```bash
python -m unittest discover -s tests -v
```

Beklenen çıktının sonu:

```text
Ran 6 tests in ...s

OK
```
